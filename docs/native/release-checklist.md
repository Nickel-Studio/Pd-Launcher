# 发布前检查清单

发布 Palladium 之前，逐项确认下面的内容。没有实际结果的项目保持未完成；不要用文档、脚本帮助或单个测试代替完整验证。

## 平台状态

| 平台 | 当前结果 |
| --- | --- |
| Windows x64 | 完整构建与 CTest 通过，可产出单文件 `pd-launcher.exe`；未签名，未在干净机器验证。 |
| Linux x64 | 核心业务域构建与测试通过；图形界面、安装包与真实窗口未验证。 |
| macOS | 没有真机编译、测试、部署或签名结果。 |

## 构建与产物

- [ ] 同一次源码与依赖生成完整应用（UI + 测试），并跑通全部 CTest。
- [ ] 生产构建从单独的 `TESTS=OFF` 目录生成，并安装到空目录。
- [ ] 记录产物字节数与 SHA256；确认 Windows 单文件不依赖同目录非系统 DLL。
- [ ] 检查 import 表（Windows）或 `ldd` / `otool`（其他平台），确认依赖闭合。

## 功能

- [ ] 首次启动、EULA 接受/拒绝、重启与命令行一次派发。
- [ ] 微软、Yggdrasil 与离线登录，角色选择与刷新。
- [ ] 原版与 Forge、NeoForge、Fabric、Quilt、OptiFine、LiteLoader 的安装与启动。
- [ ] Modrinth / CurseForge 检索、下载、取消与镜像回退。
- [ ] 实例选择、继承设置、改名与删除，Mod 启禁与更新。
- [ ] `.mrpack` 与便携包导入导出，白名单排除敏感数据。

## 视觉与交互

- [ ] 900×600、1100×720 与大窗口，100/125/150/200% DPI。
- [ ] 12 个颜色主题与明暗模式；首页、全部路由、对话框、错误与空状态。
- [ ] 字体、中文输入法、键盘焦点、辅助功能与“减少动态效果”。

## 性能

- [ ] 同机、同平台、同功能比较完整 Release，记录包体、启动、内存与进程树。
- [ ] 至少 10 次内存与 20 次启动采样，报告压缩下载与部署后大小。
- [ ] 当前 Windows 实测的包体与启动仍高于既定目标；未达标前不发布。
