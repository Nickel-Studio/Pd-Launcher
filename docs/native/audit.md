# 实现状态与已知限制

本文记录原生版实现到什么程度、哪些地方还没有验证。它不替代构建和测试结果；实际命令见 [开发与构建](development.md)。

## 已实现

- 纯 C++20 + Qt Widgets 的启动器，Windows x64 可完整构建并通过测试。
- 配置根选择、JSON 读写与 AES-GCM v1 凭据存储；实例与档案命名、便携标记 schema 1。
- 网络传输、下载预算、任务取消/提交与 ZIP/TAR 安全解包。
- 版本元数据、加载器安装计划、Java/内存/参数组装与游戏进程启动准备。
- 微软、Yggdrasil 与离线账号，皮肤图片解码。
- Modrinth / CurseForge 社区资源检索与受限正文渲染。
- 七个路由、自绘界面、明暗模式与 12 个颜色主题。

## 尚未验证

- **macOS**：没有真机编译、CTest、部署或签名结果。
- **Linux**：只有核心业务域；Qt/UI 构建、安装包与真实窗口未验证。
- **Windows**：未签名；未在干净机器、完整业务矩阵、真实游戏与视觉配对下验收。
- **性能**：包体、启动与内存尚未达到既定目标，也没有正式发布结论。
- **交互细节**：部分界面动作、取消竞争与恢复流程只在受控 fixture 中覆盖。

## 安全与数据

- 只用合成账号、独立测试根与受控服务验证；不读取真实用户秘密。
- 事务或恢复失败时保留 journal / stage / backup 与错误码，不删除 `credentials.key`、锁或 `.nickel-*` 材料。
- 日志有界并脱敏；错误报告只引用属于本次 launch/task 的路径。
