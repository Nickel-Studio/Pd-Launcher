# 使用 Palladium

Palladium（Pd / 钯）是 Minecraft Java 版启动器。第一次使用时把它放在可写目录，启动后按提示完成首次确认，再选择实例与账号。

完整的界面操作、数据位置和恢复说明见 [原生版使用指南](native/user-guide.md)；本文只列最常用的步骤。

## 第一次启动

- Windows：运行 `pd-launcher.exe`。
- Linux：`chmod u+x ./pd-launcher` 后运行。当前 Linux 版只验证过核心业务域，没有经过验证的图形界面构建。
- macOS：尚未在真机验证，没有可用的运行结果。

首次运行时会在程序旁创建配置目录 `Nickel` 与游戏目录 `.minecraft`，或者使用已有的系统配置根。把程序放在只读目录会导致配置写入失败。

## 账号

- 微软正版：选择“正版”，按提示在浏览器完成设备码授权；构建时需提供公共客户端 ID。
- 皮肤站：填写 LittleSkin 或兼容 Yggdrasil 的站点地址，登录后选择角色。
- 离线：在“设置 → 账号与隐私”填写离线用户名。

## 实例与游戏

“选择版本”登记已有游戏目录并选择实例；实例卡片的菜单可以收藏、删除或进入设置。全局 Java、内存、窗口和启动参数在“设置 → 游戏”，实例设置可逐项继承或覆盖。修改展示名不会移动实例目录。

## 下载与资源

“资源 → 原版游戏”安装原版与 Forge、NeoForge、Fabric、OptiFine、LiteLoader；“资源 → 社区资源”检索 Modrinth / CurseForge。右下角下载按钮打开下载中心，可按任务取消；取消会等待当前收尾完成。

## 外观与导出

“设置 → 外观”分别选择明暗模式和颜色主题，可以设置本地背景、模糊与遮罩。导出支持标准 `.mrpack`，以及带启动器、外观和实例设置的便携 ZIP。

## 数据

配置根按“显式便携包 → 已有系统配置 → 程序旁 `Nickel`”选择。账号、密钥、实例与缓存都从同一个根读取。

| 文件 | 用途 |
| --- | --- |
| `settings.json` | 外观、下载与账号相关设置 |
| `accounts.json` / `active_account.json` | 账号与当前选择 |
| `credentials.key` | 已保存凭据的加密密钥 |
| `game.json` | 全局游戏设置 |
| `instances.json` | 游戏目录登记与标签 |

备份账号时请一并保存整个配置目录，尤其是 `credentials.key`；缺少或损坏该文件时，已保存的凭据无法解密。

## 常见问题

| 现象 | 操作 |
| --- | --- |
| 启动按钮不可用 | 先选择实例，并确认账号或离线用户名 |
| 找不到 Java | 在游戏设置中重新扫描，或指定满足版本要求的 64 位 Java |
| 下载很慢 | 检查文件源、速度限制和线程数；列表慢时单独调整版本列表源 |
| 无法写入配置 | 把启动器移到可写文件夹，再重新打开 |
| 游戏退出 | 在错误弹窗打开日志目录，按提示检查 Java、内存和 Mod |
| 皮肤站角色不完整 | 在首页打开角色选择，用已保存的登录信息重新获取角色列表 |

反馈故障时，请附版本、系统、游戏与加载器版本、复现步骤以及问题附近的日志，使用 [Issue](https://github.com/Nickel-Studio/Pd-Launcher/issues/new/choose)。
