# Noto text subset

© 2014-2021 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source'.

The original WOFF2 is byte-identical to src/assets/fonts/nickel-line.woff2. nickel-text-subset.ttf is its static weight-400 conversion for QFontDatabase. 109 Unicode characters, no private-use characters, no icon alphabet; it does not contain the Nickel Chinese character or slash. Use system fallback for other UI text. This is not a complete CJK font. Both font files remain under OFL-1.1; Source is not used as their primary font name. Active Palladium wordmarks are supplied raster PNGs and do not depend on this font. No font was supplied with the Palladium art package.

Upstream: https://github.com/notofonts/noto-cjk
Changes: WOFF2 decompression, variable weight instantiated at 400; 2026-11-21.
