03 / GOOD TO KNOW

出发之前。

还有疑问？
看看完整使用指南

Palladium 是免费的吗？+

是的。Palladium 免费且开源，代码采用 AGPL-3.0-only 许可，原创品牌与美术采用 CC-BY-SA-4.0。你可以查看源码、反馈问题，也可以参与改进。

开始游戏，需要准备什么？+

下载与你的系统和处理器匹配的版本，将启动器放在可写目录。选择账号，在「资源 → 原版游戏」安装版本，或添加已有游戏目录；选择实例后即可启动。Java 需要满足所选游戏版本的要求。

支持哪些账号？+

支持微软正版账号、LittleSkin 等兼容 Yggdrasil 的皮肤站和离线账号。微软登录需要配置公共客户端 ID，具体步骤见开发文档。在线游戏的使用权限由相应账号与服务决定。

可以管理 Mod 和分享整合包吗？+

可以搜索、启用、禁用和检查 Mod 更新，整理重复条目；支持导出标准 .mrpack，以及可附带启动器、外观与实例设置的便携 ZIP。

遇到问题，去哪里反馈？+

请在 GitHub Issues 提交反馈，并附上启动器版本、系统、游戏和加载器版本、复现步骤与相关日志。提交前请移除日志中的账号、令牌等敏感信息。
